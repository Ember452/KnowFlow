## 方法说明

- **串行基准**: 子任务逐个执行, 总耗时为各子任务耗时之和(静态模式实测; 真实模式见下)。
- **并发执行**: 全部子任务经 agents/concurrent.py 的 run_concurrent(asyncio.gather + 超时 + 降级)同时执行, 总耗时为最慢子任务耗时。
- **下降率**: (串行耗时 - 并发耗时) / 串行耗时。静态模式下串行/并发均实测; 子任务模拟耗时覆盖真实检索/工具调用量级(1.2-2.2s)。
- 理论下降率基于参考延迟计算(串行=各耗时之和, 并发=最大耗时), 与实测对比验证执行器调度开销。
