## 五、已知限制

1. **静态模式 FC 准确率为代理指标**: 用规则关键词匹配模拟 Skill 激活, 「预期工具在可见集中」
   不等同真实 LLM Function Calling 准确率。真实模式需 LLM API Key, 运行
   `scripts/benchmark_tools.py --mode real` 由 ToolOrchestrator 跑完整工具调用循环后统计。

2. **search_tool 依赖 duckduckgo-search**: 未安装时 execute 返回失败 ToolResult(权限校验通过,
   依赖问题非越权)。单测验证 subagent 角色可调用 search_tool, 实际搜索需安装依赖。

3. **Skill 启停为进程内状态**: 不落库, 进程重启后回到 SKILL.md 声明的 enabled 初值。
   多实例部署时各实例独立(后续可接 Redis 共享状态)。

4. **沙盒文件系统基于 MinIO 前缀**: workspace 不需显式创建, 首次写入即生效。
   TTL 清理由上层按 session_ttl_seconds 调度(本模块只提供清理能力, 不内置定时器)。

5. **对话工具链路依赖外部服务就绪**: chat 端点默认注入 ToolOrchestrator, 其构造依赖
   MinIO/检索器单例; 依赖未就绪时降级为直连检索链路(工具调用不可用, 不影响普通问答)。
   P7 上下文工程的 spiller 真实沙盒切换(P9 任务 8)依赖 P7 落地后完成。

6. **指标超越目标值**: 静态模式三项指标均超目标(可见工具数 -43.4% vs 目标 -34.2%,
   Token -45.2% vs 目标 -32.6%), 因当前工具集较小(6 个)且场景设计覆盖充分。
   真实模式指标可能因 LLM 意图识别精度下降而低于静态值, 以真实实测为准。
