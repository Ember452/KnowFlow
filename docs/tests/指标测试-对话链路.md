## 四、已知限制与说明

1. **P7 前历史注入为全量最近 N 轮**: 当前按 `window_max_turns=20` 直接截取消息,
   无摘要/压缩;超长会话的预算管理在 P7 上下文工程实现。
2. **工具链路(M5 接入)**: 端点默认注入 ToolOrchestrator, 预检索上下文同时注入编排器,
   LLM 可自主调用工具(如 calculator); 工具事件序列为 `tool_start → tool_end`,
   工具链路下最终答案一次性以 `token` 事件回传(不逐 token 流式);
   依赖未就绪时自动回退直连链路(逐 token 流式, 本里程碑 M4 原始行为)。
3. **LLM 单例懒加载**: `core/llm.py` 按 Settings 首次请求时构造 ChatOpenAI,
   API Key 未配置时构造不报错、调用时报错, 由 error 事件兜底。
4. **citations 存储**: assistant 消息 `citations` JSON 存 `{"citations":[...]}`
   (chunk_id/content(截断 500 字符)/score/source), 工具链路额外存 `tool_calls` 数组,
   供 trace/replay 复用。
5. **BM25 进程内增量不跨进程同步**: 检索质量在多进程部署下主要依赖向量路, 同 M3 已知限制。
